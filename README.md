# Алаш қозғалысы — цифрлық тарих кеңістігі

Готовый интерактивный сайт об истории движения Алаш. Интерфейс и весь учебный текст сайта — на казахском языке.

## Открыть сразу

- Дважды щёлкните `index.html` в этой папке; или
- Дважды щёлкните `START.bat` — Windows откроет сайт в браузере.
- Готовая копия для показа находится в `dist/index.html`.

Установка Node.js и npm для просмотра готового сайта не нужна. Интерактивность работает прямо в браузере. Семь портретов сохранены в `assets/` и включены в `dist/assets/`, поэтому карточки деятелей открываются и без интернета. При повреждении или удалении отдельного файла показывается резервный портрет с инициалами. Веб-шрифты и большая архивная фотография на главной странице по-прежнему загружаются из интернета.

## Версия для разработки

React + TypeScript исходники сохранены в `src/`. Чтобы запустить их, откройте PowerShell в этой папке и выполните:

```powershell
pnpm install
pnpm dev
```

React-вход для Vite: `dev.html`. Сборка React-версии:

```powershell
pnpm build
```

Она создаёт `react-build/`; автономную версию в `dist/` можно открыть напрямую.

## Что работает

- Якорное меню, прокрутка, индикатор прогресса и мобильная навигация.
- Переключатель светлой и тёмной темы.
- Семь интерактивных карточек деятелей с подтверждёнными историческими портретами и модальным окном биографии.
- Хронология: выбор события и кнопки «алдыңғы/келесі».
- Восемь раскрывающихся пунктов программы партии.
- Викторина из 10 вопросов с подсчётом баллов, разбором ответов и повторным прохождением.
- Адаптивная вёрстка для телефона, планшета и компьютера.
